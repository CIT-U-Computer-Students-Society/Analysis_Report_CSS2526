# Task: Exploratory Data Analysis (EDA)

## Goal
Conduct Exploratory Data Analysis (EDA) on the anonymized CSS 2526 datasets to prototype data transformations and guarantee data viability before building the React frontend.

## Purpose
To thoroughly understand the datasets and ensure we can extract the required information prior to committing to web development logic. 

## Requirements
Explore the cleaned datasets (`data_clean/`) to prepare logic for:
1. **Demographics:** Analyze Program and Year Level distributions.
2. **Time Series:** Analyze registration trends over time.
3. **Discrepancies:** Evaluate who registered in the forms vs the actual list (Complete vs Incomplete Registration).

## Deliverables
- A documented Jupyter Notebook (`notebooks/02_exploratory_data_analysis.ipynb`) containing the analysis.
